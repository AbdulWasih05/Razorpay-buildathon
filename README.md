A defense-only dispute evidence responder for India's UPI agentic stack.

Praman handles ordinary e-commerce disputes today; its differentiated module is
agent-initiated payments under UPI Reserve Pay mandates. The core insight is
that agentic evidence — agent identifier, mandate reference, protocol metadata,
conversation context — must be **captured at transaction time**, because by
dispute time it is unrecoverable: it lives with the agent platform or TPAP, not
the merchant. The transaction store is therefore the capture layer.

## Local setup

Requires Node 20+, pnpm 10, and Docker.

```bash
pnpm install
cp .env.example .env          # then fill in the keys you have
pnpm db:up                    # Postgres 16 on port 5433
pnpm db:migrate               # apply migrations
pnpm db:generate              # generate the Prisma client
```

## Verify

```bash
pnpm lint
pnpm typecheck
pnpm test
```

## Run

```bash
pnpm api:dev                  # API on http://localhost:3000
pnpm seed                     # 100 dev disputes, seeded through the capture API
```

Then:

```bash
curl localhost:3000/evidence-packs
curl localhost:3000/evidence-packs/<externalId>
curl localhost:3000/evidence-packs/<externalId>/prompt-input
curl -X POST localhost:3000/demo/agent-checkout   # live agentic capture
```

## Held-out evaluation set

Generated by a **different model from a different lab** than the dev corpus, so
it is out-of-distribution by construction rather than by promise. It is
generated once and never read during development — enforced by guard tests, not
by discipline.

```bash
pnpm holdout:generate             # replay from the committed language cache
pnpm holdout:generate -- --live   # re-record against the second provider
```
